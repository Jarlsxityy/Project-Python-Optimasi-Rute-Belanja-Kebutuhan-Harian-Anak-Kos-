## 📌 Deskripsi Proyek

Proyek ini membahas penerapan konsep Matematika Diskrit dalam mengoptimalkan rute belanja kebutuhan harian anak kos. Permasalahan yang diangkat adalah bagaimana menentukan rute perjalanan paling efisien untuk mengunjungi beberapa tempat belanja dengan mempertimbangkan jarak dan urutan kunjungan.

Dengan menerapkan konsep teori graf dan algoritma pencarian rute, proyek ini diharapkan dapat membantu menemukan jalur perjalanan yang lebih optimal sehingga menghemat waktu, jarak, dan biaya transportasi.
